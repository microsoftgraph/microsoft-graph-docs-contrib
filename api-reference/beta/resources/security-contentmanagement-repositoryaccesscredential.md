# repositoryAccessCredential resource type

Namespace: microsoft.graph.security.contentManagement

[!INCLUDE [beta-disclaimer](../../includes/beta-disclaimer.md)]

Represents the write-only **accessCredential** action parameter used to connect, discover, modify, or disconnect a [contentManagementRepository](../resources/security-contentmanagement-contentmanagementrepository.md). This type is abstract and cannot be instantiated directly. Use a [repositoryOAuthCredential](../resources/security-contentmanagement-repositoryoauthcredential.md) or [repositoryPatCredential](../resources/security-contentmanagement-repositorypatcredential.md) and distinguish derived types with `@odata.type`.
This is an abstract type.

None.

None.

None.
