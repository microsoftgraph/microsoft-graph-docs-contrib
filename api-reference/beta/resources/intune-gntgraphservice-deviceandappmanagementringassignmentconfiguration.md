# deviceAndAppManagementRingAssignmentConfiguration resource type

Namespace: microsoft.graph

[!INCLUDE [beta-disclaimer](../../includes/beta-disclaimer.md)]

> **Important:** Microsoft supports Intune /beta APIs, but they are subject to more frequent change. Microsoft recommends using version v1.0 when possible. Check an API's availability in version v1.0 using the Version selector.

> **Note:** The Microsoft Graph API for Intune requires an [active Intune license](https://go.microsoft.com/fwlink/?linkid=839381) for the tenant.

Represents a configuration that defines how a group assignment is modified within a deployment ring.

Use this type only with the **assignmentConfigurations** relationship of a [deviceAndAppManagementDeploymentRing](../resources/intune-gntgraphservice-deviceandappmanagementdeploymentring.md). Configurations are created with the deployment and are immutable. They can't be individually created, retrieved, updated, or deleted.

## Methods

None. To retrieve all configurations for a deployment, use [Get deviceAndAppManagementDeployment](../api/intune-gntgraphservice-deviceandappmanagementdeployment-get.md) with `$expand=rings($expand=assignmentConfigurations)`.

## Properties
|Property|Type|Description|
|:---|:---|:---|
|id|String|The unique identifier of the assignment configuration. Generated by the service when the deployment is created. Read-only.|
|operation|[deviceAndAppManagementAssignmentOperationType](../resources/intune-gntgraphservice-deviceandappmanagementassignmentoperationtype.md)|The assignment target change operation. Required during deployment creation. The possible values are: `add`, `unknownFutureValue`. Use `add` to add the target to the assignments from preceding rings.|
|target|[deviceAndAppManagementAssignmentTarget](../resources/intune-shared-deviceandappmanagementassignmenttarget.md)|The group target and optional assignment filter configured by the administrator. Required during deployment creation.|
|assignmentResults (deprecated)|[deviceAndAppManagementRingAssignmentResult](../resources/intune-gntgraphservice-deviceandappmanagementringassignmentresult.md) collection|The assignment status for each payload. Deprecated on August 31, 2026, with a scheduled removal date of September 15, 2026. Use the **assignmentResults** relationship on [deviceAndAppManagementDeployment](../resources/intune-gntgraphservice-deviceandappmanagementdeployment.md) instead.|

## Relationships
None.
