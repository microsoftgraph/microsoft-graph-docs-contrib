# cloudPcUserProfileSnapshotStorageDetail resource type

Namespace: microsoft.graph

[!INCLUDE [beta-disclaimer](../../includes/beta-disclaimer.md)]

Represents the target storage details for exporting user settings persistence cloud profile snapshots. Used as the **storageDetail** parameter of the [Bulk export user profile snapshot](../api/cloudpcusersettingspersistencedetail-bulkexportuserprofilesnapshot.md) action to bundle the destination storage settings into a single parameter. Customers should first use the existing [Get storage accounts](../api/cloudpcsnapshot-getstorageaccounts.md) and [Get subscriptions](../api/cloudpcsnapshot-getsubscriptions.md) functions from the [snapshot](../resources/cloudpcsnapshot.md) resource to discover available storage accounts.

## Methods

None.

## Properties

|Property|Type|Description|
|:---|:---|:---|
|accessTier|[cloudPcStorageAccountAccessTier](../resources/cloudpcforensicstorageaccount.md#cloudpcstorageaccountaccesstier-values)|Indicates the storage access tier for exported snapshots. Possible values are: `hot`, `cool`, `premium`, `cold`. Default value is `hot`. Nullable.|
|containerName|String|Indicates the name of the target container the snapshots are exported to. The destination blob name is generated by the service per snapshot. Not nullable.|
|storageAccountId|String|Indicates the Azure resource ID of the target storage account the snapshots are exported to. For example, `/subscriptions/{subId}/resourceGroups/{rg}/providers/Microsoft.Storage/storageAccounts/{name}`. Not nullable.|

## Relationships

None.
