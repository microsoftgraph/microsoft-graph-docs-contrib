# incidentConfiguration resource type

Namespace: microsoft.graph.security

[!INCLUDE [beta-disclaimer](../../includes/beta-disclaimer.md)]

Contains settings used by the **incidentConfiguration** property of a [detectionAction](../resources/security-detectionaction.md) to control how alerts generated by a custom detection rule are associated with incidents.

## Properties

|Property|Type|Description|
|:---|:---|:---|
|isExcludedFromIncidentCorrelation|Boolean|Indicates whether alerts generated by the rule are excluded from automatic incident correlation. When `true`, each alert creates a standalone, single-alert incident. When `false`, alerts can be correlated with other related alerts. The default is `false`. On create, `null` or omission defaults to `false`. On update, `null` or omission leaves the existing value unchanged.|

## Relationships

None.
