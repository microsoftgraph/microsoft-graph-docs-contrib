# Json resource type

Namespace: microsoft.graph

[!INCLUDE [beta-disclaimer](../../includes/beta-disclaimer.md)]

Represents data returned in JSON format.

The Content Hub APIs use this type for the **dependencies** and **mainTemplate** properties of the [contentItem](../resources/security-contentmanagement-contentitem.md), [contentPackage](../resources/security-contentmanagement-contentpackage.md), and [installedPackage](../resources/security-contentmanagement-installedpackage.md) resources.

## Properties
None.

## Relationships
None.
