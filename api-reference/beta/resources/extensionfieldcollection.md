# extensionFieldCollection resource type

Namespace: microsoft.graph

[!INCLUDE [beta-disclaimer](../../includes/beta-disclaimer.md)]

The **extensions** property of the [bucket](../resources/bucket.md) resource uses this type. The **extensions** property of the [categoryDefinition](../resources/categorydefinition.md) resource uses this type. The **extensions** property of the [checklistItemV4](../resources/checklistitemv4.md) resource uses this type. The **extensions** property of the [contentLink](../resources/contentlink.md) resource uses this type. The **extensions** property of the [customChoiceOption](../resources/customchoiceoption.md) resource uses this type. The **extensions** property of the [dependency](../resources/dependency.md) resource uses this type. The **extensions** property of the [goal](../resources/goal.md) resource uses this type. The **extensions** property of the [plan](../resources/plan.md) resource uses this type. The **extensions** property of the [task](../resources/task.md) resource uses this type.

An open-type property bag that holds custom extension fields for an entity in the Planner Unified plans Graph API. Because it's an open type, any additional property name and value pair can be added to it.

This resource is an open type.

None.
