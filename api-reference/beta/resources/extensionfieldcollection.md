# extensionFieldCollection resource type

Namespace: microsoft.graph

[!INCLUDE [beta-disclaimer](../../includes/beta-disclaimer.md)]

The **extensions** property of the [bucket](bucket.md) resource uses this type. The **extensions** property of the [categoryDefinition](categorydefinition.md) resource uses this type. The **extensions** property of the [checklistItemV4](checklistitemv4.md) resource uses this type. The **extensions** property of the [contentLink](contentlink.md) resource uses this type. The **extensions** property of the [customChoiceOption](customchoiceoption.md) resource uses this type. The **extensions** property of the [dependency](dependency.md) resource uses this type. The **extensions** property of the [goal](goal.md) resource uses this type. The **extensions** property of the [plan](plan.md) resource uses this type. The **extensions** property of the [task](task.md) resource uses this type.

An open-type property bag that holds custom extension fields for a Planner V4 entity. Because it's an open type, any additional property name and value pair can be added to it.

This resource is an open type.

## Properties
None.
