# deploymentIdentity resource type

Namespace: microsoft.graph.security.contentManagement

[!INCLUDE [beta-disclaimer](../../includes/beta-disclaimer.md)]

Represents the **deploymentIdentity** property or connect action parameter of a [contentManagementRepository](../resources/security-contentmanagement-contentmanagementrepository.md). This type is abstract and cannot be instantiated directly. Use a [servicePrincipalDeploymentIdentity](../resources/security-contentmanagement-serviceprincipaldeploymentidentity.md) or [managedIdentityDeploymentIdentity](../resources/security-contentmanagement-managedidentitydeploymentidentity.md) and distinguish derived types with `@odata.type`.
This is an abstract type.


## Methods

None.

## Properties

None.

## Relationships
None.
