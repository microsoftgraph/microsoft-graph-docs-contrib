> [!IMPORTANT]
> For delegated access using work or school accounts, the signed-in user must be assigned a supported built-in [Microsoft Entra role](/entra/identity/role-based-access-control/permissions-reference?toc=%2Fgraph%2Ftoc.json), in addition to the required Microsoft Graph permission. The following built-in roles are supported, listed from least to most privileged:
> - Security Reader
> - Security Administrator
>
> **Security Reader** is the least privileged role supported for this operation.
