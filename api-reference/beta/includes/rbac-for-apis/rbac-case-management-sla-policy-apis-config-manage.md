> [!IMPORTANT]
> For delegated access using work or school accounts, the signed-in user must be assigned a supported built-in [Microsoft Entra role](/entra/identity/role-based-access-control/permissions-reference?toc=%2Fgraph%2Ftoc.json), in addition to the `CaseManagement.ConfigManage.All` permission. **Security Administrator** is the least privileged role supported for this operation.
