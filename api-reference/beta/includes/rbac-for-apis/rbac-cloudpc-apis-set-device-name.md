> [!NOTE]
> For delegated access using work or school accounts, the signed-in user must have the `CloudPCs/SetDeviceName` permission through [Windows 365 role-based access control](/windows-365/enterprise/role-based-access), in addition to the Microsoft Graph permission. The **Cloud PC Administrator** role or a custom role that grants this permission can be used. Supported Microsoft Entra roles include **Windows 365 Administrator** and **Intune Administrator**.
>
> For scoped role assignments, the target Cloud PC must also be within the user's assigned [scope groups](/windows-365/enterprise/role-based-access#scope-groups) and [scope tags](/windows-365/enterprise/role-based-access#scope-tags). These user role requirements don't apply to application-only access.
