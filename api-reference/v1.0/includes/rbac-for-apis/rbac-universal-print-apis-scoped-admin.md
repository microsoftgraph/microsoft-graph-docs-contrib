> [!IMPORTANT]
> For delegated access using work or school accounts, the signed-in user must be assigned a supported [Microsoft Entra role](/entra/identity/role-based-access-control/permissions-reference?toc=%2Fgraph%2Ftoc.json). *Printer Administrator* is the least privileged role supported for this operation. The role can be assigned at tenant scope or to an [administrative unit](/universal-print/delegated-administration) that contains the specified printer.
