> [!IMPORTANT]
> For delegated access using work or school accounts, the signed-in user must be assigned a supported [Microsoft Entra role](/entra/identity/role-based-access-control/permissions-reference?toc=%2Fgraph%2Ftoc.json). *Printer Technician* is the least privileged role supported for this operation. *Printer Administrator* is also supported, including assignments scoped to an administrative unit.
