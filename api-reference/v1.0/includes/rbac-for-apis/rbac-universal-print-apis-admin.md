> [!IMPORTANT]
> For delegated access using work or school accounts, the signed-in user must have a tenant-wide assignment to a supported [Microsoft Entra role](/entra/identity/role-based-access-control/permissions-reference?toc=%2Fgraph%2Ftoc.json). *Printer Administrator* is the least privileged role supported for this operation.
